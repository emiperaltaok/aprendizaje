Las 2 reglas fundamentales
Lo que no cambia sin importar el sistema que construyas.
01
1 dominio → muchos archivos
Un dominio puede tener todos los archivos que necesite. Lo que los une es que todos hablan del mismo tema de negocio.
02
1 archivo → 1 responsabilidad
Cada archivo hace una sola cosa. Si necesitas cambiar algo, sabes exactamente donde ir sin tocar lo que no corresponde.

Buena vs mala practica
El error mas comun: mezclar responsabilidades en un mismo archivo.
MAL
// reservarTurno.ts
reservarTurno()
cobrarTurno() ← NO
enviarFactura() ← NO
registrarPaciente() ← NO
Un archivo que hace de todo. Si cambia la logica de cobro, tenes que tocar el archivo de turnos. No tiene sentido.
BIEN
// reservarTurno.ts
reservarTurno() ← SI
verificarDisponibilidad() ← SI

// cobrarTurno.ts
cobrarTurno() ← SI
Cada archivo en su lugar. Si cambia el cobro, vas directo a cobrarTurno.ts. Nada mas.

Lo que puede vivir adentro de un archivo
Los 7 tipos de elementos mas comunes en TypeScript / JavaScript.
FUNCION
function hacerAlgo()
Bloque de codigo que ejecuta una tarea y puede devolver un resultado.
INTERFACE
interface Turno {}
Define la forma exacta que debe tener un objeto. Solo en TypeScript.
CONSTANTE
const LIMITE = 10
Valor fijo que no cambia durante la ejecucion del sistema.
HOOK
function useTurnos()
Funcion especial de React que maneja estado y efectos. Siempre empieza con "use".
TYPE
type Estado = string
Alias de tipo. Similar a interface pero mas flexible. Solo en TypeScript.
CLASE
class Paciente {}
Objeto con propiedades y metodos. Menos comun en React moderno.
